# AetherWebOS 内置应用名录

全部 **35 个**内置应用的速览,分组排列。清单与接入方式见
[app-dev-guide.md](app-dev-guide.md);系统整体结构见
[architecture.md](architecture.md)。

表头约定:

- **窗口**:多实例 = 可同时开多个窗口(9 个);单实例 = 再次打开聚焦
  已有窗口并转发参数;
- **分发**:预装 = 开箱即在开始菜单与桌面;商店 = 清单标 `store: true`,
  **默认未安装**(共 19 个),在「软件商店」里安装——安装即真实资源
  下载,按用户隔离,详见 [architecture.md](architecture.md) §5/§6。

## 系统与文件(8)

| 应用 | id | 窗口 | 分发 | 说明 |
|---|---|---|---|---|
| 文件管家 | files | 多实例 | 预装 | 目录树、右键操作、压缩包与加密文件;多窗口对照浏览与跨窗拖拽 |
| 本地资源 | localfiles | 多实例 | 预装 | 浏览本机真实文件,授权后导入系统使用 |
| 文件预览 | viewer | 多实例 | 预装 | 图片、音视频与 PDF 的轻量预览 |
| 回收站 | trash | 单实例 | 预装 | 还原误删的文件,或彻底删除 |
| 软件商店 | appstore | 单实例 | 预装 | 发现并安装新应用(真实资源下载、按用户隔离) |
| 系统设置 | settings | 单实例 | 预装 | 主题、壁纸、账号与系统状态 |
| 系统监视器 | monitor | 单实例 | 商店 | IPC 消息流量与系统资源观测台 |
| 终端 | terminal | 多实例 | 预装 | Bash 风格,管道与重定向齐备;`node <脚本.ajs>` 跑 AetherJS、`./程序.exe` 免 node 直击,`ssh` 进模拟远程终端,另有 snap / chmod / notify / vol 等 |
